# تغییرات — «تومانِ شناسه» برای کارت‌به‌کارت (PAY-5)

فایل‌های تازه:
- `database/migrations/2026_10_16_000005_add_amount_suffix_to_orders.php`

فایل‌های تغییرکرده:
- `OrderService`: `uniqueSuffix` و مبلغِ سفارشِ کارت‌به‌کارت
- `Order`: ستونِ `amount_suffix` (در API هم)
- `OrderResource`: شناسه زیرِ مبلغ، جستجو با مبلغ، مبلغ به ریال در پنجره‌ی تأیید
- `config/shop.php`، `.env.example`: `CARD_UNIQUE_MAX`
- `tests/Feature/OrderFlowTest.php`: ۲ تستِ تازه
- `ARCHITECTURE-backend.md`

## چه شد
- **مبلغِ سفارش:** به مبلغِ هر سفارشِ کارت‌به‌کارت عددی تصادفی از ۱ تا ۹۹۹ تومان اضافه می‌شود.
  مثلاً کتابِ ۱۸۰٬۰۰۰ تومانی ← ۱۸۰٬۴۱۷.
  - هیچ دو سفارشِ کارت‌به‌کارتِ بازی (در انتظارِ پرداخت یا بررسی) مبلغِ یکسان ندارند.
  - پس هر واریز در صورت‌حسابِ بانک فقط به یک سفارش می‌خورد.
- **پنل، «سفارش‌ها»:**
  - **زیرِ مبلغ:** «شناسه: ۴۱۷ تومان».
  - **جستجو:** مبلغِ صورت‌حساب را جستجو کنید، با یا بدونِ جداکننده یا ارقامِ فارسی، مثلاً
    `180417` یا `۱۸۰,۴۱۷`؛ همان سفارش پیدا می‌شود. اگر بانک به ریال نشان می‌دهد، صفرِ آخر را
    بردارید.
  - **پنجره‌ی «تأیید»:** مبلغِ دقیق را به تومان و ریال می‌گوید.
- **اپ:** مبلغِ دقیق با دکمه‌ی کپی و یک توضیح: «دقیقاً همین مبلغ را واریز کنید، نه عددِ رُند».
- **درگاه:** شناسه ندارد. `CARD_UNIQUE_MAX=0` شناسه را خاموش می‌کند.
