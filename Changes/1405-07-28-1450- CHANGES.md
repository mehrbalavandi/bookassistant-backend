# تغییرات — ورودِ پنل از فرمِ سایت تا مرورگر رمز را ذخیره/به‌روز کند (SITE-14)؛ تغییرِ رمز برای همه

## چه شد
- **«به‌روزرسانیِ رمز؟» در Google Password Manager و مانندش:** فرمِ ورودِ خودِ پنل (‎/admin/login‎، همان
  «Sign in» انگلیسی) با Livewire فرستاده می‌شود و مرورگر آن را ورودِ موفق تشخیص نمی‌داد؛ پس رمزِ تازه
  ذخیره نمی‌شد و «به‌روز شود؟» نمی‌آمد. حالا ‎/admin/login‎ (و انقضای نشستِ پنل) به صفحه‌ی ورودِ سایت می‌رود
  که فرمِ HTMLِ معمولی است. با رمزِ تازه وارد شوید، مرورگر می‌پرسد رمزِ ذخیره‌شده را به‌روز کند.
  - اگر ورودِ ایمیلی برای کاربران خاموش باشد، ادمین‌ها از ‎/login?for=admin‎ («ورودِ مدیران») وارد می‌شوند.
- **تغییرِ رمز برای همه‌ی کاربران:** داشبوردِ کاربران (صفحه‌ی اصلی بعد از ورود، که سربرگِ سایت را نداشت)
  حالا «🔑 تغییرِ رمز» و «💬 انتقادات و پیشنهادات» دارد (برای کاربرانِ ایمیل‌دار).

## فایل‌ها
- `app/Filament/Pages/Auth/Login.php` (تازه)، `AdminPanelProvider` (`->login(...)`)
- `AuthMethods::adminLoginUrl()`، `AdminAuthenticate`، `AdminAuthenticateSession`
- `WebAuthController`، `auth/login.blade.php` (حالتِ ورودِ مدیران)، `dashboard.blade.php`
