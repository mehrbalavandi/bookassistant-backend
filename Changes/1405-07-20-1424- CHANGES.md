# تغییرات — توزیعِ اپ از سایت (صفحه‌ی `/app`، API نسخه، پنلِ «نسخه‌های اپ»)

اپ در هیچ فروشگاهی (بازار، مایکت، گوگل‌پلی) نیست، پس از خودِ سایت دانلود می‌شود. اپ
با هر نسخه‌ی تازه به کاربر خبر می‌دهد و او را به همین صفحه می‌فرستد.

تغییرِ هم‌زمان در ielts_assistant: بررسیِ نسخه، دیالوگ و دکمه‌ها (قانون‌های U-1 تا U-4).

## ۱. جدولِ `app_releases`
| ستون | معنی |
|---|---|
| `platform` | `android` یا `windows` |
| `version_name` | نسخه‌ی نمایشی، مثلاً 1.0.1 |
| `build_number` | عددِ مقایسه؛ یکتا در هر سکو |
| `file_path`، `file_size` | فایلِ نصبی (دیسکِ خصوصیِ `local`، پوشه‌ی `app-releases/`) |
| `changelog` | تغییرات؛ هر خط یک بند |
| `is_mandatory` | اجباری |
| `is_published` | منتشرشده |

- با جایگزینیِ فایل، فایلِ قبلی پاک می‌شود.
- با حذفِ نسخه، فایلش هم پاک می‌شود.
- حجم خودکار از روی دیسک خوانده می‌شود.

## ۲. پنلِ ادمین ← «نسخه‌های اپ»
- **فرم:**
  - سکو.
  - نسخه.
  - شماره‌ی build: پیش‌فرض یکی بعد از آخرین. تکراری‌بودن در همان سکو با پیامِ فارسی
    رد می‌شود.
  - فایل: APK یا فایلِ نصبیِ ویندوز. سقفِ حجم همان سقفِ آپلودِ کتاب‌هاست.
  - تغییرات.
  - «اجباری» و «منتشرشده».
- **جدول:** فیلترِ سکو؛ مرتب از جدیدترین.

## ۳. صفحه‌ی `/app` (برای موبایل هم)
- برای هر سکو یک کارت: نسخه، حجم، تاریخ، نشانِ «اجباری»، دکمه‌ی دانلود و فهرستِ
  تغییرات.
- کارتِ سکوی همان دستگاه بالا می‌آید و حاشیه‌ی رنگی می‌گیرد.
- راهنمای نصب در اندروید («نصب از منابعِ ناشناخته»، نصب روی همان برنامه بدونِ ازدست‌رفتنِ
  کتاب‌ها).
- در سربرگِ صفحه‌ی اصلی (مهمان و کاربرِ واردشده) دکمه‌ی «📱 دریافتِ اپ» اضافه شد.

## ۴. مسیرها
| مسیر | کار |
|---|---|
| `GET /app` | صفحه‌ی دانلود (`app.page`) |
| `GET /app/download/{android\|windows}` | فایلِ آخرین نسخه‌ی منتشرشده، با نامِ `ielts-assistant-1.0.1.apk`؛ دانلودِ ادامه‌دار (Range) پشتیبانی می‌شود. بدونِ نسخه: 404. |
| `GET /api/app/latest?platform=android` | آخرین نسخه برای اپ. سکوی ناشناخته: 422. |

پاسخِ `/api/app/latest`:
```json
{"success": true, "data": {
  "platform": "android", "version_name": "1.0.1", "build_number": 2,
  "changelog": "…", "is_mandatory": false, "min_supported_build": 0,
  "file_size": 31457280, "published_at": "…",
  "page_url": "https://…/app", "download_url": "https://…/app/download/android"
}}
```
- `data` اگر هنوز نسخه‌ای منتشر نشده باشد `null` است.
- «آخرین نسخه» = بیشترین build در میانِ نسخه‌های منتشرشده‌ای که فایل دارند.
- `min_supported_build` = بیشترین build در میانِ نسخه‌های منتشرشده‌ی اجباری. اپی که
  buildش کمتر از این است باید به‌روز کند.

## کارهایی که شما باید بکنید
```
php artisan migrate
```
بعد از آن، در پنل نسخه‌ی فعلیِ اپ را منتشر کنید تا صفحه‌ی `/app` خالی نباشد.

**روالِ هر انتشار:**
1. در فلاتر `version` در pubspec را بالا ببرید. عددِ بعد از `+` حتماً بیشتر شود.
2. APK را بسازید.
3. در پنل منتشر کنید: نسخه = قبل از `+`، build = بعد از `+`.
