# تغییرات — ۴۱۹، رمزِ ویرایشِ کاربر، صفحه‌ی کتاب، پشتیبان‌گیری، انتقادات و پیشنهادات، سفارش‌های ناتمام، کتابِ بی‌محتوا

## چه شد
- **«419 | PAGE EXPIRED»:** در پنل دیگر پنجره‌ی سفید نمی‌آید؛ وقتی نشست یا صفحه منقضی شده، صفحه یک‌بار
  از نو بار می‌شود (اگر نشست تمام شده، صفحه‌ی ورود). علتِ اصلی بررسیِ خودکارِ اعلان‌ها هر ۳۰ ثانیه بود.
  در سایت، فرمِ منقضی با همان مقدارها و پیامِ «دوباره بفرستید» برمی‌گردد.
- **«12345678» در ویرایشِ کاربر:** کارِ مرورگر بود (رمزِ ذخیره‌شده‌ی خودِ ادمین را پر می‌کرد). حالا فیلد
  خالی می‌ماند. رمزِ فعلیِ کاربر را نمی‌شود نشان داد: فقط هَشِ یک‌طرفه‌اش ذخیره است.
- **صفحه‌ی ویرایشِ کتاب** بعد از آپلود/حذفِ محتوا خودش از نو بار می‌شود.
- **پشتیبان‌گیری** (منوی پنل): ساختن/دانلود/آپلود/حذف/بازگردانی + پشتیبانِ خودکارِ شبانه.
- **انتقادات و پیشنهادات:** صفحه‌ی `/feedback` در سایت (با تصویر)، API برای اپ، و بخشِ پنل با پاسخ.
- **سفارش‌های ناتمام** بعد از خریدِ همان کتاب با روشِ دیگر خودکار حذف می‌شوند (داده‌ی قبلی هم).
- **کتابِ بی‌محتوا** خریدنی نیست؛ ویترین «در حالِ آماده‌سازی» نشان می‌دهد.

## بعد از استقرار
- `php artisan migrate` (جدول‌های پیام‌ها و پاک‌کردنِ سفارش‌های ناتمامِ قبلی).
- cron برای `php artisan schedule:run` (اگر ندارید) — پشتیبانِ شبانه و لغوِ سفارش‌های رهاشده.
